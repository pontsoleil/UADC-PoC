# EN CIUS canonical taxonomy snapshot

This directory contains the approved deterministic EN CIUS taxonomy snapshot for version `2026-07-05` and the Canonical 18-column HMD used to generate it.

- Canonical HMD: `EN16931_CIUS_Invoice_Canonical_HMD.csv`
- HMD module identity: `en16931`
- XPath lexical prefix: `en`
- Namespace: `http://www.xbrl.org/int/gl/en16931/2026-07-05`
- Tuple entry point: `tuple/en16931_Invoice/en16931-all-2026-07-05.xsd`
- OIM entry point: `oim/en16931_Invoice/en16931-all-oim-2026-07-05.xsd`

The taxonomy is generated by the common `tools/taxonomy/xBRLGL_TaxonomyGenerator.py`. The shared `taxonomy/gen/gl-gen-2026-12-31.xsd` source schema is a required Generator input and is version-normalized into the output package. From the repository root, generate into a new, empty output directory with:

```text
python -B tools/taxonomy/xBRLGL_TaxonomyGenerator.py \
  --hmd-dir definitions/taxonomy/en-cius \
  --output-dir <empty-output-directory> \
  --namespace http://www.xbrl.org/int/gl/en16931/2026-07-05 \
  --namespace-prefix-map en=en16931 \
  --datatype-mapping definitions/taxonomy/datatype_mapping.csv \
  --datatype-override definitions/taxonomy/datatype_override.csv
```

The Canonical HMD can be validated without changing it:

```text
python -B tools/taxonomy/prepare_hmd_for_taxonomy.py \
  definitions/taxonomy/en-cius/EN16931_CIUS_Invoice_Canonical_HMD.csv \
  --profile canonical \
  --namespace-mode module-based \
  --namespace-prefix en \
  --validation-only
```

`definitions/taxonomy/en-cius` is the controlled Canonical snapshot. `out/taxonomy` is the runtime deployment; corresponding generated files must remain byte-identical to this snapshot. Legacy runtime assets may coexist in `out/taxonomy` and are not part of this Canonical 13-file set.
