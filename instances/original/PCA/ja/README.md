# PCA合成年間デモ

本データは、PCA形式の構造や会計上の取引パターンを参考に独自生成した合成デモデータです。PCA社が提供するサンプル会計データそのもの、またはその匿名化版ではありません。PCA社による認証、保証、推奨を示すものでもありません。

## 目的

本データは、このプロジェクトが実装するPCA形式の81列物理CSVレイアウトを使用して、UADCとLedgerExplorerの相互運用性を検証するためのものです。

## データ概要

| 項目 | 値 |
| --- | ---: |
| データ行数 | 1,271 |
| 仕訳数 | 708 |
| 科目coverage | 58 / 58 |
| 部門 | 6 |
| 取引先 | 29 |
| 架空銀行 | 3 |
| Public-data safety | PASS |
| Synthetic independence | PASS |

対象期間は2021年4月から2022年3月です。1:1、N:1、1:N、N:Mの仕訳パターンを含みます。各仕訳は貸借一致し、名称、摘要、日付、伝票番号、金額、開始残高、取引関係は固定seed `20260903`で独自生成しています。

## 生成期間と残高検証

本合成会計シナリオは、公開対象となる12か月の会計年度に加え、前2か月・後2か月を含む16か月の期間で生成しています。前2か月は、売掛金・買掛金等を含む開始残高を経済的に自然な形で導出するために使用します。後2か月は、期末時点で残る売掛金、買掛金、未払金および一時勘定が翌期に決済されることを検証するために使用します。

本ディレクトリで公開するCSVには、2021年4月から2022年3月までの会計年度12か月分のみを収録します。前2か月・後2か月は内部の生成・検証contextとして保持し、このCSVには含めません。

## 制約と状態

状態: Canonical WORKに配置した検証済み公開デモデータです。本データは相互運用性検証用であり、本番会計データではありません。また、すべてのPCA製品・版との互換性を保証または認証するものではありません。内部テスト証跡は、この公開instance directoryには配置していません。
