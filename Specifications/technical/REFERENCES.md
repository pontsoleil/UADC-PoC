# External references

This Candidate contains project-authored semantic descriptions and processing
tables. It does not reproduce CEN standards text, official tables, or official
business-rule prose.

- EN 16931 bibliographic reference: CEN, *Electronic invoicing — Part 1:
  Semantic data model of the core elements of an electronic invoice*.
- CII syntax mapping bibliographic reference: CEN/TS 16931-3-3:2020.
- XBRL GL 2017 source and license: https://www.xbrl.org/int/gl/2016-12-01/gl-framework-2017-PWD-2016-12-01.html
- UN/CEFACT UNCL 1001, D.24A: source for the identified invoice and
  credit-note subset used by the EE1 domain.
