# XBRL Japan experimental namespace authorization

- Approval date: 2026-08-27
- Authorizing party: explicit approval by the project owner
- Scope: `https://www.xbrl.or.jp/taxonomy/xbrl-gl-next/experimental/2026-12-31/{module}`

namespace on a domain managed by XBRL Japan. The project intends to migrate to
an official XBRL International namespace if and when one is assigned. Use of
this namespace does not make this package an XBRL Japan or XBRL International
